| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

---

## Reporting a Vulnerability

We take the security of **Zine Scraper Suite** seriously. If you discover a security vulnerability or exploit:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via email or our community Discord:
   * **Email**: [valsedeanshu@gmail.com](mailto:valsedeanshu@gmail.com)
   * **Discord**: [https://discord.gg/suJD5xtFj](https://discord.gg/suJD5xtFj) (Contact @Valse / Anshu directly)
3. Provide detailed steps to reproduce the issue, along with any relevant proof-of-concept scripts or logs.

We will review, acknowledge, and resolve security issues promptly before releasing patched versions.
