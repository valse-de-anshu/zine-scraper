## 1. Overview & Problem Statement

YouTube hosts two distinct types of subtitles:
1. **Manual / Creator-Uploaded Subtitles (`--write-sub`)**: Fixed, human-transcribed subtitle tracks.
2. **AI-Generated Automatic Captions (`--write-auto-sub`)**: Server-side Automatic Speech Recognition (ASR) transcripts generated by YouTube's speech models, along with real-time AI auto-translations into 100+ languages.

When building scrapers or lyric/caption visualizers, extracting raw subtitle streams poses several hurdles:
- **Rolling Word Timestamps**: YouTube ASR emits progressive micro-chunks (`<00:00:01.234> word <00:00:01.567>`) which cause stuttering or duplicate line rendering if parsed naively.
- **XML / HTML Tags**: Formats like `<c.colorE5E5E5>`, `<font>`, and `position:0%` pollute raw subtitle text.
- **Variable Formats**: Tracks can be returned as JSON3, TTML, SRV3, or VTT.

---

## 2. The `yt-dlp` AI Subtitle Extraction Recipe

To reliably extract AI-generated captions without downloading the video payload:

```bash
yt-dlp \
  --no-warnings --quiet --no-playlist \
  --skip-download \
  --write-auto-sub \
  --write-sub \
  --sub-format "vtt/lrc/best" \
  --sub-langs "en,en.*,en-orig,en-US,en-GB,hi,hi.*,hin,hi-orig,all" \
  -o "output_dir/sub.%(ext)s" \
  "<YOUTUBE_URL_OR_SEARCH_QUERY>"
```

### Key Parameter Breakdown

| Flag | Purpose |
|---|---|
| `--skip-download` | Bypasses video/audio stream download; only retrieves metadata and subtitle tracks. |
| `--write-auto-sub` | Explicitly queries YouTube's AI ASR / automatic caption servers. |
| `--write-sub` | Queries official/creator-uploaded subtitle files. |
| `--sub-format "vtt/lrc/best"` | Forces yt-dlp to convert internal XML/JSON3 subtitle streams into standard WebVTT or LRC. |
| `--sub-langs "..."` | Language priority pattern. YouTube appends `-orig` to original AI tracks (e.g. `en-orig`, `hi-orig`). |

## 3. Language & Source Prioritization Cascade

YouTube outputs files with specific naming conventions:
- `sub.en.vtt` ➔ Official / Manual English
- `sub.en-orig.vtt` ➔ AI Auto-generated Original English
- `sub.hi.vtt` ➔ Official / Manual Hindi
- `sub.hi-orig.vtt` ➔ AI Auto-generated Original Hindi
- `sub.en-hi.vtt` ➔ AI Auto-translated (English to Hindi)

### Priority Sorting Logic

```python
def subtitle_priority(filename: str) -> int:
    f_lower = filename.lower()
    # 1. Manual / Official English
    if f_lower.endswith(".en.vtt") or f_lower.endswith(".en.lrc"):
        return 0
    # 2. AI Auto-generated English
    if ".en-orig" in f_lower or ".en" in f_lower or "english" in f_lower:
        return 1
    # 3. Manual / Official Hindi
    if f_lower.endswith(".hi.vtt") or f_lower.endswith(".hi.lrc"):
        return 2
    # 4. AI Auto-generated Hindi
    if ".hi-orig" in f_lower or ".hi" in f_lower or "hindi" in f_lower or "hin" in f_lower:
        return 3
    # 5. Fallback / Auto-translated tracks
    return 4
```

## 4. WebVTT Normalization & Cleaning Pipeline

YouTube AI auto-captions contain rolling words, duplicate lines, and markup. The following parser cleans every block into a clean timeline:

```python
import re
import html

def parse_vtt(vtt_content: str) -> list[dict]:
    """
    Parses raw WebVTT into a normalized list: [{'time': float, 'text': str}, ...]
    """
    lines = []
    blocks = vtt_content.split("\n\n")

    for block in blocks:
        block = block.strip()
        if not block or block.startswith("WEBVTT") or block.startswith("Kind:") or block.startswith("Language:"):
            continue

        # Match standard or short timestamp format (00:00:00.000 --> 00:00:00.000)
        ts_match = re.search(r"(\d{2}):(\d{2}):(\d{2}\.\d+)\s*-->", block)
        if not ts_match:
            ts_match = re.search(r"(\d{2}):(\d{2}\.\d+)\s*-->", block)
            if ts_match:
                mins = int(ts_match.group(1))
                secs = float(ts_match.group(2))
                timestamp = mins * 60 + secs
            else:
                continue
        else:
            hrs = int(ts_match.group(1))
            mins = int(ts_match.group(2))
            secs = float(ts_match.group(3))
            timestamp = hrs * 3600 + mins * 60 + secs

        # Extract text content excluding header/timing lines
        text_lines = [
            line.strip() for line in block.splitlines()
            if "-->" not in line and not line.isdigit()
        ]
        text = " ".join(text_lines).strip()

        # 1. Strip inline HTML/XML tags and word timestamps (<c.color...>, <00:00:01.234>)
        text = re.sub(r"<[^>]+>", "", text)

        # 2. Decode HTML entities (&amp;, &#39;, &quot;, &nbsp;)
        text = html.unescape(text)

        # 3. Clean music/applause markers if desired
        text = re.sub(r"^♪\s*|\s*♪$", "", text).strip()

        # 4. Deduplicate consecutive repeated lines (common in rolling ASR)
        if text and (not lines or lines[-1]["text"] != text):
            lines.append({"time": timestamp, "text": text})

    return sorted(lines, key=lambda x: x["time"])
```

## 5. Plug-and-Play Template for **Zine Scraper**

Here is a self-contained, standalone Python module ready to be imported into Zine Scraper:

```python
"""
Zine Scraper - YouTube AI Subtitles & Metadata Extraction Module
"""

import os
import tempfile
import subprocess
import html
import re

class YouTubeSubtitlesExtractor:
    def __init__(self, timeout: int = 120):
        self.timeout = timeout

    def fetch_subtitles(self, video_url_or_query: str) -> list[dict]:
        """
        Fetches official or AI auto-generated subtitles for a given YouTube URL or search query.
        Returns: [{'time': float, 'text': str}, ...]
        """
        with tempfile.TemporaryDirectory() as tmpdir:
            out_tmpl = os.path.join(tmpdir, "sub.%(ext)s")
            cmd = [
                "yt-dlp",
                "--no-warnings", "--quiet", "--no-playlist",
                "--write-auto-sub", "--write-sub",
                "--sub-format", "vtt/lrc/best",
                "--sub-langs", "en,en.*,en-orig,en-US,en-GB,hi,hi.*,hin,hi-orig,all",
                "--skip-download",
                "-o", out_tmpl,
                video_url_or_query
            ]

            try:
                subprocess.run(cmd, stdout=subprocess.PIPE, stderr=subprocess.PIPE, timeout=self.timeout)
            except Exception as e:
                print(f"[ZineScraper] Error invoking yt-dlp: {e}")
                return []

            def _priority(f: str) -> int:
                fl = f.lower()
                if fl.endswith(".en.vtt") or fl.endswith(".en.lrc"): return 0
                if ".en-orig" in fl or ".en" in fl or "english" in fl: return 1
                if fl.endswith(".hi.vtt") or fl.endswith(".hi.lrc"): return 2
                if ".hi-orig" in fl or ".hi" in fl or "hindi" in fl or "hin" in fl: return 3
                return 4

            files = sorted(os.listdir(tmpdir), key=_priority)
            for fname in files:
                fpath = os.path.join(tmpdir, fname)
                with open(fpath, "r", encoding="utf-8", errors="ignore") as fp:
                    content = fp.read()
                    if fname.endswith(".vtt"):
                        parsed = parse_vtt(content)
                        if parsed:
                            return parsed
                    elif fname.endswith(".lrc"):
                        # Parse LRC if returned
                        pass

        return []
```

## 6. Integration Checklist for Zine Scraper
